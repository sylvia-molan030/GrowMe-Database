# GrowMe 上线指南

## 第一步：push 代码到 GitHub

```bash
cd /Users/sylvia/Desktop/sylvia/growme
git push origin main
```

- Username：`sylvia-molan030`
- Password：GitHub Token（https://github.com/settings/tokens 生成，勾选 **repo**）

## 第二步：开启 Pages

打开：https://github.com/sylvia-molan030/GrowMe-Database/settings/pages

| 选项 | 选择 |
|------|------|
| Source | Deploy from a branch |
| Branch | main |
| 文件夹 | **/docs** |

点 Save，等 1～3 分钟。

## 第三步：访问网站

https://sylvia-molan030.github.io/GrowMe-Database/
